## Key vocabulary (in your own words)

- repository: its like the main folder of your project
- commit: this saves your work, like a save button
- branch: this makes a version of your project where you can change stuff without affecting your project unless you push and pull
- push / pull: when you push, it uploads what you are working on, to other projects / branches, when you pull, you take what the other pushes.
- pull request: pull rq is for when multiple people are working together and someone wants to save their work on the main project.
- merge conflict: when two people changed the same thing and pushed. merge conflct will choose which work to take.
